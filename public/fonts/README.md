# UI fonts

The application serves these fonts locally. Their original licenses apply to the
font files independently of the application's AGPL license.

- Inter: normal and italic variable WOFF2, weights 100–900, from
  https://github.com/rsms/inter/tree/master/docs/font-files.
  License: `Inter-LICENSE.txt` (SIL Open Font License 1.1).
- JetBrains Mono: normal variable TrueType, weights 100–800, from
  https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/variable.
  License: `JetBrainsMono-LICENSE.txt` (SIL Open Font License 1.1).

Downloaded on 2026-10-11. These files are unmodified upstream assets.
