ThreatSumm4ry - API endpoints (server/index.js)
Total: 46 HTTP endpoints

Guard legend:
  [auth]   GitHub session cookie required (requireAuth)
  [admin]  session + login na admin list (requireAdmin; GITHUB_ADMIN_LOGINS)
  [secret] server-to-server, X-Feed-Secret header (worker only)
  [rl]     rate-limited (scanLimiter)
  (blank)  public
